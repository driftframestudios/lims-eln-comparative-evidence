# Legacy control-plane quarantine

This directory preserves earlier experiments in evidence admission, acceptance and
decision receipts, simulated closure, Coordination Horizon runtime material, custom
branch and repository validation, and cross-repository binding structures.

The contents are inactive reference material. The active package, workflows, and
vendor-comparison contracts have no dependency on this directory. A future reuse
proposal can extract one small pattern after identifying a concrete unmet need and
comparing established framework support.
