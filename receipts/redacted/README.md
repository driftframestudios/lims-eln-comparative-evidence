# Redacted receipt manifests

This directory is reserved for reviewed receipt manifests that are suitable for
source control. This release includes no environment receipt. Unit tests construct a
generated observed receipt inside the test boundary to execute the schema.

A future committed manifest identifies the claim, exact environment and
implementation, scenario, observed result, raw-artifact digest, governed locator,
limitations, performer, reviewer, accountable approver where applicable, and retest
triggers.

Sensitive values are represented by classification labels and content digests.
Authorized reviewers follow the governed locator for raw evidence.
